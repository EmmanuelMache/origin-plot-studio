Put one csv file per phase in this folder to teach the app a phase that is not in its library.

Columns: d (in Å) or 2theta (Cu Kα1), and relative intensity in %. h, k, l are optional.
Name the file after the phase with its label code in brackets, for example:
    Portlandite (CH).csv
    Ettringite (AFt).csv
The code in brackets is the label drawn on the graphs.

The easiest source: in HighScore open the reference pattern (ICDD or COD card) and export its
peak list as csv.

Since version 5.12 the better way is the window XRD tools > Phase library in the app:
"Add phase from file" stores the phase outside the app folder, so it stays when you install a new
version. New phases of the files you draw are stored there by the app itself. Files in THIS folder
belong to this copy of the app only.
