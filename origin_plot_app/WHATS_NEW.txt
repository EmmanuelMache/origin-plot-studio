# One line per version, newest first. The first line is shown when the app offers an update.
5.54.6  Fixed: the gallery's search box, class tree and file/source filters could silently stop hiding anything once a file was ticked (a Qt quirk in the 'best fit first' reordering). New: 'Use what the app recommends' beside 'Draw my data like this' - tick your file(s) and it picks and draws the best-fitting template for you. The best fit (★) now updates as soon as a file is ticked. 'House figures' in the class tree is grouped by instrument / technique now, not one flat list.
5.54.5  Visual polish: readable search box text on the header bar, the app's own flat look for scroll bars and menus, the Files panel's 'Add files…' button no longer clipped (it is the clear first action now), lightly shaded alternating table rows, and a soft hover / shadow lift on template pictures and the Assistant's input box.
5.54.4  Fixed: loading a multi-sheet workbook with no sheet called 'Data' now picks the sheet that fits the ticked template, not just the one with the most numeric columns. An instrument export's leading row-number column ('No.', '#') is no longer drawn as if it were the x / position column, a 'decimal commas' export keeps its real header text, and a pattern file's almost-empty text column is no longer mistaken for a peak list.
5.54.3  Fixed: without a console window (the usual way of starting the app), a command that failed used to do nothing visible - Qt swallowed the error silently. A failed command is now written to error_log.txt (next to the app) and shown in the status bar; Help > Open the error log... opens it, and it is included in Problem report. If something still 'does not work', this file says why.
5.54.2  The phase library is part of the app again (19 phases, 1889 reflections: clinker phases, feldspars, micas, carbonates, quartz, gypsum and more), without any reference to samples. Nothing has to be installed by hand.
5.54.1  Analysis > Graphs and templates: 'House figures' at the top of the classes shows the house figure layouts (stacked XRD with zoom, fit with tick rows, TG-DTG panels, calorimetry, particle size ...) in one click; 'My templates' right below it.
5.54.0  One place for graphs: the Graph gallery is now inside Analysis (top bar: Workspace, Analysis, Assistant, Settings). Analysis opens 'Graphs and templates' - the picture gallery where you tick your files and the pictures of the graphs you want - with a switch to 'Calculations' (the analysis tools). The 26 workbook graph types (G01-G24, C01, C02) are pictures in that gallery, under their technique, and are drawn from your workbooks like any other picture. Your loaded files appear in the gallery's Files list at once.

Zoom / inset can be switched off in the XRD and calorimetry templates. Cumulative heat of your own files is now in J/g (x 3.6).
